Representación gráfica · Bloque 1

El estudio completo de una función

Once pasos para dibujar cualquier función sin dar valores al azar: dominio, cortes, simetría, asíntotas, crecimiento, extremos, curvatura e inflexión.

1 El orden de trabajo

Para representar una función no damos valores al azar: seguimos siempre los mismos pasos, y cada uno usa lo que ya sabemos del anterior. Es el esquema que tienes en la portada del tema.

1 · DominioDónde existe la función.
2 · Cortes con los ejesEje OY: x = 0. Eje OX: f(x) = 0.
3 · SimetríaPar: f(−x) = f(x). Impar: f(−x) = −f(x).
4 · AsíntotasVerticales, horizontales u oblicuas.
5 · Crecimiento y decrecimientoSigno de f′(x).
6 · Extremos relativosf′(x) = 0 y cambio de signo de f′.
7 · CurvaturaSigno de f″(x).
8 · Puntos de inflexiónf″(x) = 0 y cambio de signo de f″.
9 · Tabla de valoresAlgunos puntos más, si hacen falta.
10 · RegionesDónde f es positiva o negativa.
11 · GráficaReunir toda la información y dibujar.

En este bloque vemos qué se calcula en cada paso. En los bloques siguientes lo aplicamos a cada familia de funciones.

2 Dominio

¿Dónde puede fallar una función?
PolinomioDominio ℝ.
Cociente \(\dfrac{N(x)}{D(x)}\)Se quitan los valores con D(x) = 0.
Raíz de índice par \(\sqrt{g(x)}\)g(x) ≥ 0.
Logaritmo \(\ln g(x)\)g(x) > 0.
Exponencial \(e^{g(x)}\)El dominio de g.
📝 Ejemplo resuelto

a) \(f(x) = \dfrac{x+1}{x^2-4}\): \(x^2 - 4 = 0 \Rightarrow x = \pm 2\). Dominio: \(\mathbb{R} - \{-2, 2\}\).

b) \(g(x) = \sqrt{6-2x}\): \(6 - 2x \ge 0 \Rightarrow x \le 3\). Dominio: \((-\infty, 3]\).

c) \(h(x) = \ln(x^2-9)\): \(x^2 - 9 > 0 \Rightarrow x < -3\) o \(x > 3\). Dominio: \((-\infty, -3) \cup (3, +\infty)\).

3 Cortes con los ejes y simetría

Eje OY: se sustituye x = 0 (solo si 0 está en el dominio): punto (0, f(0)). Eje OX: se resuelve f(x) = 0: puntos (x, 0).

Par: f(−x) = f(x) → simétrica respecto al eje OY

Impar: f(−x) = −f(x) → simétrica respecto al origen

📝 Ejemplo resuelto · f(x) = x³ − 3x

Cortes: f(0) = 0 → (0, 0). \(x^3 - 3x\)\({}= x(x^2-3)\)\({}= 0\)\({}\Rightarrow x\)\({}= 0,\ x\)\({}= \pm\sqrt3\).

Simetría: \(f(-x)\)\({}= (-x)^3 - 3(-x)\)\({}= -x^3 + 3x\)\({}= -f(x)\) → es impar: simétrica respecto al origen. Basta estudiarla para x ≥ 0.

4 Asíntotas

Vertical x = a\(\lim_{x\to a} f(x) = \pm\infty\). Se buscan donde se anula un denominador o en el borde del dominio de un logaritmo.
Horizontal y = L\(\lim_{x\to\pm\infty} f(x) = L\) (un número).
Oblicua y = mx + n\(m = \lim_{x\to\pm\infty}\dfrac{f(x)}{x} \ne 0\), \(n = \lim_{x\to\pm\infty}\big(f(x) - mx\big)\).

f(x) = (x + 1)/(x − 2): AV x = 2, AH y = 1

f(x) = (x² + 1)/x: AV x = 0, AO y = x

⚠️Por un mismo lado (x → +∞ o x → −∞) una función no puede tener a la vez asíntota horizontal y oblicua. Los polinomios no tienen asíntotas.
📝 Ejemplo resuelto · f(x) = (x² + 1)/x

AV: el denominador se anula en x = 0 y \(\lim_{x\to0^+} f(x) = +\infty\), \(\lim_{x\to0^-} f(x) = -\infty\) → AV x = 0.

AH: \(\lim_{x\to\pm\infty}\frac{x^2+1}{x}\)\({}= \pm\infty\) → no hay.

AO: \(m = \lim \frac{x^2+1}{x^2} = 1\); \(n = \lim\left(\frac{x^2+1}{x} - x\right)\)\({}= \lim \frac1x\)\({}= 0\) → AO \(y = x\).

5 Crecimiento y extremos relativos

Con la primera derivada

Si f′(x) > 0 en un intervalo, f es creciente; si f′(x) < 0, es decreciente.

Los extremos relativos están entre los puntos con f′(x) = 0 (puntos críticos): si f′ pasa de + a −, hay un máximo; de − a +, un mínimo. También sirve el criterio de la segunda derivada: f″(x₀) < 0 → máximo; f″(x₀) > 0 → mínimo.

📝 Ejemplo resuelto · f(x) = x³ − 3x

\(f'(x)\)\({}= 3x^2 - 3\)\({}= 3(x-1)(x+1)\)\({}= 0\)\({}\Rightarrow x\)\({}= \pm 1\).

x(−∞, −1)−1(−1, 1)1(1, +∞)
f′(x)+0−0+
f(x)↗máx↘mín↗

Crece en \((-\infty,-1)\cup(1,+\infty)\) y decrece en \((-1,1)\). Máximo \((-1, f(-1)) = (-1, 2)\); mínimo \((1, -2)\).

6 Curvatura y puntos de inflexión

Con la segunda derivada

Si f″(x) > 0, f es cóncava hacia arriba ∪; si f″(x) < 0, cóncava hacia abajo ∩. Un punto de inflexión es donde cambia la curvatura: f″(x) = 0 y f″ cambia de signo.

⚠️f″(x₀) = 0 no basta: f(x) = x⁴ tiene f″(0) = 0 pero es cóncava ∪ a los dos lados, así que (0, 0) no es de inflexión (es un mínimo).
📝 Ejemplo resuelto · f(x) = x³ − 3x

\(f''(x) = 6x = 0 \Rightarrow x = 0\). Para x < 0, f″ < 0 (∩); para x > 0, f″ > 0 (∪). Cambia de signo → punto de inflexión (0, 0).

7 Regiones y gráfica final

Con los cortes con el eje OX sabemos dónde f es positiva (la gráfica va por encima del eje) o negativa (por debajo). Juntando todo dibujamos la gráfica:

📝 Resumen · f(x) = x³ − 3x

Dominio ℝ · impar · cortes (0, 0), (±√3, 0) · sin asíntotas · máximo (−1, 2), mínimo (1, −2) · cóncava ∩ en (−∞, 0) y ∪ en (0, +∞) · inflexión (0, 0) · positiva en (−√3, 0) ∪ (√3, +∞).

Funciones polinómicas

De la recta y la parábola a cualquier polinomio: comportamiento en el infinito, estudio completo con derivadas y cálculo de coeficientes.

1 De la recta a cualquier polinomio

Las funciones polinómicas tienen dominio ℝ, son continuas y derivables en todo ℝ y no tienen asíntotas. Las de grado 1 y 2 ya las conoces:

Recta \(f(x) = mx + n\)Pendiente m: si m > 0 crece, si m < 0 decrece. Sin extremos.
Parábola \(f(x) = ax^2 + bx + c\)Vértice en \(x = -\dfrac{b}{2a}\) (donde f′ = 0). Si a > 0, ∪ con un mínimo; si a < 0, ∩ con un máximo.
Grado nHasta n − 1 extremos relativos y hasta n − 2 puntos de inflexión. Corta al eje OX como mucho n veces.
📝 Ejemplo resuelto · La parábola con derivadas

\(f(x) = x^2 - 6x + 5\): \(f'(x) = 2x - 6 = 0 \Rightarrow x = 3\); \(f(3) = -4\). Como f″ = 2 > 0, el vértice \((3, -4)\) es un mínimo. Cortes: (0, 5), y \(x^2 - 6x + 5 = 0 \Rightarrow x = 1, 5\).

2 Comportamiento en el infinito

Para |x| muy grande manda el término de mayor grado, \(a_nx^n\):

Impar, a > 0: −∞ ← → +∞

Impar, a < 0: +∞ ← → −∞

Par, a > 0: +∞ ← → +∞

📝 Ejemplo resuelto

\(\lim_{x\to+\infty}(-2x^3 + 5x^2)\)\({}= -\infty\) y \(\lim_{x\to-\infty}(-2x^3 + 5x^2)\)\({}= +\infty\): grado impar con coeficiente negativo, la gráfica «baja» hacia la derecha.

3 Estudio completo de una cuártica

📝 Ejemplo resuelto · f(x) = x⁴ − 2x²

Dominio y simetría: ℝ; solo potencias pares → f(−x) = f(x): par.

Cortes: (0, 0); \(x^2(x^2-2)\)\({}= 0\)\({}\Rightarrow x\)\({}= 0,\ \pm\sqrt2\).

Monotonía: \(f'(x)\)\({}= 4x^3 - 4x\)\({}= 4x(x-1)(x+1)\)\({}= 0\)\({}\Rightarrow x\)\({}= -1, 0, 1\). Signo de f′: − en (−∞, −1), + en (−1, 0), − en (0, 1), + en (1, +∞).

Extremos: mínimos \((-1, -1)\) y \((1, -1)\); máximo \((0, 0)\).

Curvatura: \(f''(x)\)\({}= 12x^2 - 4\)\({}= 0\)\({}\Rightarrow x\)\({}= \pm\frac{1}{\sqrt3}\). ∪ fuera de \(\left(-\frac{1}{\sqrt3}, \frac{1}{\sqrt3}\right)\) y ∩ dentro. Inflexión en \(\left(\pm\frac{1}{\sqrt3}, -\frac59\right)\).

4 Un extremo que no lo es

📝 Ejemplo resuelto · f(x) = x⁴ − 4x³

\(f'(x)\)\({}= 4x^3 - 12x^2\)\({}= 4x^2(x - 3)\)\({}= 0\)\({}\Rightarrow x\)\({}= 0\) (doble) o \(x = 3\).

En x = 0, f′ es negativa a los dos lados (4x² ≥ 0 y x − 3 < 0): no hay extremo, aunque f′(0) = 0. En x = 3 pasa de − a +: mínimo (3, −27).

\(f''(x) = 12x^2 - 24x = 12x(x-2)\): inflexión en x = 0 y en x = 2. En x = 0 la tangente es horizontal y además hay inflexión.

5 Hallar los coeficientes de un polinomio

Cada dato del enunciado se traduce en una ecuación: «pasa por (a, b)» → f(a) = b; «extremo en x = a» → f′(a) = 0; «inflexión en x = a» → f″(a) = 0.

📝 Ejemplo resuelto · Tipo PEvAU

Halla a, b y c para que \(f(x) = x^3 + ax^2 + bx + c\) tenga un punto de inflexión en x = 1, un extremo relativo en x = 3 y corte al eje OY en y = 2.

\(f'(x) = 3x^2 + 2ax + b\), \(f''(x) = 6x + 2a\).

• Inflexión en x = 1: \(f''(1)\)\({}= 6 + 2a\)\({}= 0\)\({}\Rightarrow a\)\({}= -3\).
• Extremo en x = 3: \(f'(3)\)\({}= 27 + 6a + b\)\({}= 0\)\({}\Rightarrow 27 - 18 + b\)\({}= 0\)\({}\Rightarrow b\)\({}= -9\).
• f(0) = 2: \(c = 2\).

\(f(x) = x^3 - 3x^2 - 9x + 2\). Como \(f''(3) = 12 > 0\), en x = 3 hay un mínimo, \((3, -25)\); el otro punto crítico, x = −1, es un máximo, \((-1, 7)\).
